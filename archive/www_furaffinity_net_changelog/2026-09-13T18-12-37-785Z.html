Fur Affinity | Changelog

Update - 06/18/2026


General

  • Added [time] BBCode

Update - 06/12/2026


General

  • Added Comment Management page (Currently only available on Beta)
  • Added External URL link filter page
  • Added announcement page as well as the announcement notification (A).
  • Modern light news overlay no longer hard to read.
  • Fixed HR BBCode missing padding and thickness of the original hr.
  • Various optimizations to speed up large content page loads by up to 80%.

Search

  • Fixed Buttons on search page not being consistent.

Gallery

  • SFW settings now respected when user viewing their own gallery.
    • This is does not apply to the submissions management page to allow users to view and manage all their works.

Submission

  • Fixed a bug with the submission page's main content side getting to wide due to long non-breaking strings.
  • Further fixes for sidebar smooshing.
  • Fixed Flash container not resizing properly on specific pages.
  • Updated Ruffle to 0.2.0 stable.
  • Submission Favorited list updated to match how Watch lists work.

Update - 05/14/2026


General

  • BBCode [hr] updated to use our internal hr bbcode css to make it more consistent.

Submission

  • Reworked the submission page
    • Now a single page to make it easier to work with and more consistent between devices.
    • Report button improved to be more generalized.
    • Folder list trunscates at 5 folders to keep things manageable.
    • Various other small improvements.

Update - 05/01/2026


Userpage

  • Shouts are now hidden instead of immediately deleted.
  • VGen added to contacts.

Update - 04/14/2026


General

  • Notifications older than 6 months have been pruned.
  • Notifications are now visually capped at 9999. (It’s over 9,000!!)
    • You will still receive notifications beyond 9999, but they will not show on the top menu.
  • Visited links now have a different color.
    • We will be polishing up some inconsistencies once Tech has had a chance to catch up on some much needed sleep!

Submission Page

  • Mini-gallery from Beta is now available to everyone!

Update - 12/12/2025


General

  • [url] now allow for emails.
    • [url=mailto:EMAILADDRESS] is all you need for it to be parsed.
  • Micro optimizations to the BBCode parsing system, cutting the time nearly in half.
  • Further non-tagged URL Parsing improvements.
    • Non-tag URL parsing is still very experimental and needs further tuning until we're comfortable with it.
  • New list BBCode improvements, still experimental so not entirely supported yet.

Watchlist

  • Fixed a bug where an empty watch list would return an error.

Update - 11/28/2025


General

  • BBCode has been reworked to be more secure.
  • New [ol], [ul], and [li] bbcode. This code is still in beta but should be functional.
  • Updated rating colors to be a little easier on the eyes.

Journals

  • Journals can now be rated by the usual rating system.

Update - 11/11/2025


General

  • Profile images on comments no longer stretch vertically and should show properly.
  • Implemented IPv6 support.
  • BBCode colors should now be more visible regardless of how dark/light the background is.

Upload Content

  • PDF reader should now allow for printing and downloads.
  • Image viewer's "click to close" message now reduced to a red X
  • RTF submissions with hyperlinks now have a prompt when clicking on an external link to alert the user that they're leaving the website.

Userpage

  • Favorited disabled user content will not show on the favorite page and userpage.
  • Pagination improvements for Journals.

Update - 09/22/2025


General

  • Disabled "Segue UI Emoji" for the time being, needs more research.
    • This was intended to address the unicode oddities with non-Chrome browsers, but caused some oddities of it's own.
  • Fixed a bug that made usernames with special characters in them not work correctly with the content block system.
  • Added support for additional time zones.
  • Added support for toggling between 12 and 24 hour formats, where applicable.
  • Currently have a rough version of automatic DST support.
    • Note: JavaScript must be enabled for this feature to work, and will work based on your system time. If JavaScript is not enabled, it will default back to your Account Settings option.
  • Accounts made after the post date of this journal will be unable to switch to the Classic Site Layout/Theme, as we continue to phase out this deprecated option.

Upload Content

  • Rich Text Formatting (RTF) should now be nearly 99% accurate. There will still be funkiness but it no longer lacks a majority of the HTML it has now.
    • If you continue to see any issues, please open a Trouble Ticket so our Tech Team can address it!
  • Plain text (TXT) and RTF viewers no longer have a dark/light mode and instead default to an off-white to ensure color formatting isn't messed up by the dark background.
  • Document viewers are now more responsive and should resize with the browser window.
  • Comic Neue now works within the TXT and RTF viewers.
  • PDF Viewer should now work on some older browsers/devices that were unable to parse newer JavaScript.
  • The image viewer on the submission page should no longer jumpscare you by showing the image maximized when you go to clear a censor blur.
    • You can now clear a blur with a click, then click again to show the image viewer.
  • Reduced the size of the "Click HERE to close" button below expanded images as well as only showing on smaller screen resolutions.

Wall-o-Awesome

  • Updated the Wall-o-Awesome visibility notice to be clearer.
  • Added monetary values to mascot donation bars to help show progress.

Userpage

  • Fixed issues with users being unable to click the "Leave Shout" button.
  • Updated the shout box and counter to use the proper text length.
  • Shouts no longer truncate with a "..." and instead output as expected.
  • Comments/Shouts avatars now don't stretch width-wise.
  • Contact info values now truncate more gradually.

Account settings

  • Updated the Date of Birth field to a proper calendar field.
  • The content pages for disabled accounts should now no longer be accessible even if the person trying to access the content has a direct link to the page.
